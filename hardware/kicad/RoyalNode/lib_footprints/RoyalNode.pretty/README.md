# RoyalNode Project Footprints

This `.pretty` directory is reserved for project-local footprints that have been checked against the Rev A footprint release matrix.

Do not add generic substitutions for the high-risk parts:

- EBYTE E22-900M33S
- Molex 0732511150 edge-launch SMA
- TI BQ25798 RQM0029A
- TI TPS61088 RHL0020A
- AMASS XT30PW-M

Every released footprint should include:

- Manufacturer part number in the footprint description
- Drawing/CAD source in the footprint description
- Pin-1 or polarity marking where applicable
- Courtyard including mating/clearance space for connectors
- No test pads, measurement shunts, or bench-only geometry
